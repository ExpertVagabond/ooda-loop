The OODA Loop

Observe. Orient. Decide. Act.

O

Observe

Read codebase, parse task queue, understand context. Map file structure and dependencies.

O

Orient

Apply HVE constraints. Select model (7b for simple, 14b for complex). Plan implementation approach.

D

Decide

Generate code via Ollama/Codebuff/Aider. Apply coding constraints. Prepare for testing.

A

Act

Run tests. If pass: commit + review. If fail: rollback + retry. Reviewer creates follow-up tasks.

Inner Loop: Generate → Test → Retry · Outer Loop: Review → Grade → New Tasks
